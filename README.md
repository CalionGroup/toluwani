# Valentine's Website 💕

An interactive Valentine's Day website built with React and Vite, featuring a playful "No" button that runs away and an adorable animated cat character!

## Features

- 🎨 Beautiful pink gradient background with floating hearts
- 🐱 Animated cat character that reacts to interactions
- 💕 Interactive "No" button that moves away when you try to hover or click it
- ✨ Celebratory animation when "Yes" is clicked
- 📱 Fully responsive design

## Setup Instructions

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

## How It Works

- When you hover over or try to click the "No" button, it randomly moves to a different position
- The cat's expression changes to "worried" when you approach the "No" button
- Clicking "Yes" triggers a celebration screen with hearts and a happy cat
- Floating hearts animate in the background throughout

## Technologies Used

- React 18
- Vite
- CSS3 (animations, gradients, transforms)
- SVG for the cat character
- Google Fonts (Pacifico & Quicksand)

## Customization

You can easily customize:
- Colors in `App.css` (gradient backgrounds, button colors)
- Text in `App.jsx` (question, success message)
- Cat design in the SVG elements
- Animation speeds and effects
